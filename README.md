# RIZZIERI ONE — V:1.11.0

PWA "Life, Business & Projects" — central única para projetos, eventos, financeiro e vida pessoal em
quatro workspaces (Negócios, Eventos, Pessoal, Ideias).

## Estrutura
```
index.html / css/app.css / js/app.js / manifest.json / sw.js / assets/icons/ / SECURITY.md
```

## Publicar no GitHub Pages
```
git init && git add . && git commit -m "RIZZIERI ONE V:1.11.0"
git remote add origin <seu-repositorio> && git push -u origin main
```
Settings → Pages → branch `main`, pasta raiz.

## Novidades desta versão
Aviso sobre permissões (câmera/avisos) em Ajustes → Ajuda, e anotação visível de que a senha de
acesso real (bloqueio de verdade) fica prevista para versão futura.

## Dados
localStorage do navegador. Baixe backup em Ajustes → Ajuda/Backup antes de trocar de aparelho.
